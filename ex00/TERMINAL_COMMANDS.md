# ex00 - Comandos do Terminal

## Objetivo
Exibir um arquivo com caracteres especiais no terminal.

## Comandos Utilizados

### 1. Criar o arquivo com conteúdo
```bash
echo "Z" > z
```

### 2. Verificar o conteúdo
```bash
cat z
```

## Resultado
O arquivo `z` contém o caractere "Z" que é exibido no terminal.
